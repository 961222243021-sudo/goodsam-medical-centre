# Goodsam Medical Centre

Responsive hospital website for Goodsam Medical Centre, Chinnamanur, Tamil Nadu.

## Features

- White and dark blue hospital layout with original Goodsam branding
- Smooth looping zoom animation on the supplied hospital photograph
- General Medicine, General Surgery, ENT and Dentistry sections
- Vision and Mission, plus the 25-year anniversary banner
- Department details and WhatsApp appointment enquiries
- Click-to-call links, social logos, and embedded Google Map
- Mobile navigation, responsive cards and reduced-motion support

## Deploy to Vercel

1. Import this GitHub repository in Vercel.
2. Set Framework Preset to **Other**.
3. Keep Root Directory at the repository root.
4. Leave Build Command and Install Command empty.
5. Set Output Directory to **dist**.
6. Click Deploy.

The included `vercel.json` supplies these settings. No API keys, dependencies or environment variables are required.

## Local preview

Run `python -m http.server 8000 --directory dist`, then open http://localhost:8000.

## Editing

- `dist/index.html`: content and layout
- `dist/style.css`: colors, responsive styles and animations
- `dist/app.js`: navigation, department dialogs and WhatsApp enquiry flow
- `dist/assets/`: hospital photo, hospital logo and icon assets
